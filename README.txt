AK TOURS & TRAVELS — WEBSITE STARTER FILES

Included:
- index.html: bilingual website page
- style.css: responsive styling
- script.js: Marathi/English toggle and WhatsApp booking enquiry form

IMPORTANT:
1. This is a starter website package, not yet published online.
2. Vehicle illustrations are emoji placeholders. Replace them with your own genuine vehicle photos before publishing for a more professional result.
3. WhatsApp booking sends an enquiry message to +91 70666 80100. It does not automatically confirm vehicle availability or collect payments.
4. Before publishing, test all details and links.

FREE PUBLISHING OPTION (GitHub Pages):
1. On a computer or mobile browser, create/sign in to a GitHub account.
2. Create a new public repository, for example: ak-tours-travels-website.
3. Upload index.html, style.css and script.js to the repository's main/root folder.
4. Open repository Settings -> Pages.
5. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
6. Wait for GitHub Pages to publish and open the generated website address shown in Settings -> Pages.
7. Test the website on your phone and test the WhatsApp booking form.

A free address will usually look like:
https://YOUR-GITHUB-USERNAME.github.io/ak-tours-travels-website/

Google Sites is an easier no-code alternative, but these HTML files cannot simply be imported into Google Sites as a full working website. For this prepared package, GitHub Pages is the more direct free publishing route.

Official guides:
- GitHub Pages: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
- Google Sites publishing: https://support.google.com/sites/answer/6372880
